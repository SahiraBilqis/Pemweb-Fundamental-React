# [Tugas 3] Pemweb Fundamental React


## Ringkasan Perubahan

Membuat aplikasi Manajemen Produk menggunakan React dan Vite dengan fitur daftar produk, pencarian, tambah, edit, dan hapus produk melalui pop-up.

Implementasi menggunakan JSX, useState, event handler, conditional rendering, dan CSS.

## Bukti Pengujian

| Skenario | Hasil yang Diharapkan | Hasil Aktual |
|---|---|---|
| Menampilkan daftar produk | 5 produk awal muncul | Sesuai |
| Mencari produk | Produk ditampilkan sesuai pencarian | Sesuai |
| Menambah produk | Produk baru muncul | Sesuai |
| Mengedit produk | Data produk diperbarui | Sesuai |
| Menghapus produk | Produk terhapus setelah konfirmasi | Sesuai |
| Validasi harga | Harga 0 ditolak | Sesuai |
